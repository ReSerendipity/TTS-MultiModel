# TTS MultiModel 对外服务合规检查清单（Compliance Checklist）

> 适用场景：将服务**公开部署**（公网服务器、对外开放 API/Web）之前逐项检查。
> 纯本地个人使用（127.0.0.1 自用）不触发下列监管义务。最后更新：2026-08-12

## 0. 服务形态判断

| 部署形态 | 是否触发 |
|---|---|
| 本机 127.0.0.1 自用 | ❌ 不触发 |
| 局域网小范围自用 | ⚠️ 保持内网 + 鉴权 |
| 公网 / 开放 API / 面向公众 Web | ✅ 触发，按下表执行 |

## 1. 对外部署前检查项

| # | 事项 | 说明 | 状态 |
|---|---|---|---|
| 1 | 算法备案评估 | 语音合成/声音克隆属深度合成技术（语音合成类）。具有舆论属性或社会动员能力的深度合成服务提供者依《互联网信息服务深度合成管理规定》第十九条履行算法备案；部署前向属地网信部门咨询或通过算法备案系统评估 | ☐ |
| 2 | 安全评估 | 依《生成式人工智能服务管理暂行办法》第十七条，具有舆论属性或社会动员能力的生成式 AI 服务须开展安全评估 | ☐ |
| 3 | AI 内容标识 | 输出音频已内嵌 FFT 频域溯源水印（source_id + content_hash + CRC32，全引擎覆盖）；对外服务还应：a) 页面/输出界面显示"AI 生成"显式标识；b) 文件元数据写入标识字段（对齐《人工智能生成合成内容标识办法》及 GB 45438-2025，元数据字段为增强项） | ☐ |
| 4 | 声音权益 | 声音克隆功能必须限制：禁止克隆他人声音（民法典第 1023 条声音保护、个人信息保护法）；服务端校验用户上传音频的授权声明 | ☐ |
| 5 | 内容管理 | 生成内容审核（禁止色情、诈骗、虚假信息——AI 语音诈骗为刑法规制重点）；建立举报流程 | ☐ |
| 6 | 用户协议 | 明确生成内容权责、禁止用途（克隆他人声音、诈骗、侵权配音）——已备 USER_AGREEMENT.md | ☐ |
| 7 | 个人信息 | 用户音频/文本可能含个人信息：告知同意、加密存储、删除渠道、隐私政策 | ☐ |
| 8 | 访问控制 | 公网部署必须鉴权；CORS 仅允许预期来源（默认仅 127.0.0.1） | ☐ |
| 9 | 日志与溯源 | 保留任务日志（文本/音频哈希、时间、账号）配合监管与侵权溯源（水印 payload 可溯源） | ☐ |
| 10 | 备案后义务 | 变更（停止/主体/算法升级）及时办理变更/注销；配合监督检查 | ☐ |

## 2. 分发/便携包检查项

| # | 事项 | 说明 | 状态 |
|---|---|---|---|
| 1 | 模型许可矩阵 | 商用发行物仅内嵌 Apache-2.0 权重（VoxCPM2/dots.tts）；IndexTTS2 商用需 bilibili 授权；NC 模型（ChatTTS/F5-TTS 等）不得内嵌 | ☐ |
| 2 | persona 合规 | personas/ 音色为 AI 原创合成（基座 VoxCPM2 Apache-2.0），衍生品可分发；测试文本已原创化 | ☐ |
| 3 | 署名保留 | Apache 2.0 第 4 条：保留版权声明、LICENSE、NOTICE | ☐ |

*本清单为初稿参考，不构成正式法律意见；具体备案与监管要求以监管机构最新口径为准。*
