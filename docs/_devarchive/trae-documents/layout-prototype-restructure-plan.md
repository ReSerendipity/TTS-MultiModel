# TTS MultiModel 布局重构 — HTML 原型生成计划 v2

> 版本: 2.0 | 日期: 2026-07-19 | 状态: 待审核

---

## 一、目标

基于 79 张 Web UI 截图的完整分析，**从零出发**设计 4 种不同的布局重构方向，生成 4 个独立 HTML 原型文件。不参考已有原型，完全根据当前页面的实际问题独立思考。

每个原型覆盖 5 个核心页面，用户可直接浏览器并排对比。

---

## 二、当前布局问题深度分析

### 2.1 当前页面结构

```
Sidebar (200px, 可折叠至 52px)
├── VOXCPM2 · 语音合成: 声音设计 / 语音克隆 / 极致克隆
├── VOXCPM2 · 语音工具: 剧本工坊 / Prompt 续写 / LoRA / LoRA 训练
├── INDEXTTS 2.0 · 语音克隆: 语音克隆 / 情感控制 / 时长控制
└── 工具: 设置 / 历史记录 / 音色库 / 帮助

Top Bar: [折叠] [页面标题] [VoxCPM2][IndexTTS 2.0][无] [none|未加载] ─── [GPU 0.00%][显存 --/--][内存 81.06%]

Main Content: 单栏内容区 + 浮动输出格式选择器(wav/mp3) + 底部全局音频播放器
```

### 2.2 截图分析发现的 7 个核心问题

| # | 问题 | 严重度 | 截图证据 | 具体表现 |
|---|------|--------|---------|---------|
| **P1** | **Sidebar 信息架构混乱** | 高 | 01-58 所有截图 | 14 个导航项分 4 组，组名使用引擎型号(VoxCPM2/IndexTTS2)作为分类维度——这是技术架构视角而非用户任务视角。用户不会想"我要用 VoxCPM2 做声音设计"，而是想"我要设计一个声音" |
| **P2** | **内容区空间利用率极低** | 高 | 01/02/12/16/20 | 单栏布局，表单宽度约占页面 60%，两侧大量留白。语音克隆页(截图12)整个视口仅一个文本框+一个下拉框+一个按钮，信息密度极低 |
| **P3** | **Top Bar 信息层级扁平** | 中 | 01/44/62 | 引擎切换器(3个按钮)、引擎状态、GPU 监视器(3个指标)、页面标题全部平铺在一行，无主次之分。GPU 数据属于系统监控，不应与核心操作(引擎切换)争夺同一视觉层级 |
| **P4** | **输出格式选择器悬浮脱节** | 中 | 01/12/20 | 格式选择器(wav/mp3)漂浮在 Top Bar 和内容区之间，既不属于导航也不属于表单，视觉上与两侧都脱节 |
| **P5** | **设置页与其他页面布局割裂** | 中 | 44/72-78 | 设置页使用完全不同的布局范式：快速导航锚点多列排列 + 引擎信息/GPU 左侧 + 高级参数/默认参数右侧双列。而其他所有页面都是单栏表单。用户在设置页和其他页面间切换时体验不连续 |
| **P6** | **情感控制页面内容过载** | 中 | 37-40 | 3 种模式切换 + 参考音频上传 + 7 个情感预设按钮 + 8 个情感权重滑块 + 合成文本 + 生成按钮，全部单列堆叠，需要大量滚动 |
| **P7** | **暗色主题一致性问题** | 低 | 63-65 | 暗色主题下底部播放器和 toast 区域与深色背景融合，视觉层次不清。帮助弹窗(截图63)在暗色背景下对比度不足 |

### 2.3 页面类型分类

从布局需求角度，14 个 Tab 可分为 3 种页面类型：

| 类型 | 页面 | 布局特征 |
|------|------|---------|
| **输入→生成型** | 声音设计、语音克隆、极致克隆、剧本工坊、Prompt 续写、IndexTTS2 克隆、情感控制、时长控制 | 左侧/上方输入表单 → 右侧/下方生成结果 |
| **数据管理型** | 音色库、历史记录 | 搜索/筛选 + 卡片或表格列表 |
| **配置型** | 设置、LoRA 管理、LoRA 训练 | 多组参数/开关/信息展示 |

## 三、4 个原型方向（独立设计）

### 设计原则

不管哪个方向，都必须解决上述 7 个问题中的至少 4 个。

---

### 方向 A：任务导向双栏

**核心理念**：将导航从"技术架构分类"重构为"用户任务分类"，内容区采用 65%/35% 双栏。

**解决的问题**：P1（导航重构）、P2（空间利用）、P3（Top Bar 精简）

**布局骨架：**
```
┌─────────────────┬───────────────────────────────────────┐
│                 │  Top Bar: [折叠][标题] ── [引擎状态]   │
│   Sidebar       ├───────────────────────┬───────────────┤
│   (192px)       │                       │               │
│                 │    输入区 (65%)        │  结果区 (35%)  │
│ 🎨 设计声音     │    表单/参数/操作      │  波形/播放     │
│ 🎭 克隆声音     │                       │  下载/保存     │
│ 📝 剧本对话     │                       │               │
│ 🎛️ 情感控制     │                       │               │
│ ⚡ 快速克隆     │                       │               │
│ ─────────       │                       │               │
│ 📊 LoRA        │                       │               │
│ 🎓 LoRA 训练   │                       │               │
│ ─────────       │                       │               │
│ ⚙️ 设置        │                       │               │
│ 📜 历史        │                       │               │
│ 👤 音色库      │                       │               │
│ ❓ 帮助        │                       │               │
│                 │                       │               │
│ [☀️][🌐][帮助]  │                       │               │
└─────────────────┴───────────────────────┴───────────────┘
```

**导航重构逻辑**：按用户任务重新分组，不再使用引擎型号分组：
- 🎨 设计与克隆（声音设计 / 语音克隆 / 极致克隆 / 剧本工坊 / Prompt 续写）
- 🌐 IndexTTS2（情感控制 / 时长控制）
- 🔧 工具与设置（LoRA / LoRA 训练 / 设置 / 历史 / 音色库 / 帮助）

**Top Bar 精简**：移除 GPU 监视器（移到底部状态栏），移除输出格式选择器（移到内容区内），仅保留页面标题 + 引擎状态指示。

**5 个页面布局：**

| 页面 | 输入区 (65%) | 结果区 (35%) |
|------|------------|------------|
| 声音设计 | 文本→语言→描述/标签→高级参数→生成 | 波形→播放→保存 |
| 语音克隆 | 文本→语言→参考音频选择→高级参数→生成 | 波形→播放→保存 |
| IndexTTS2 情感 | 模式选择→参考音频→情感预设/滑块→文本→生成 | 情感雷达图+结果 |
| 设置 | Engine Info + GPU VRAM (并排) + 参数卡片 | **隐藏**，form 区扩展至 100% |
| 音色库 | 搜索→卡片网格 (3列) | **隐藏**，form 区扩展至 100% |

**底部状态栏**：`GPU 0.00% | 显存 --/-- | 内存 81.06% | wav/mp3` — 将系统监控信息下沉到专属层级。

### 方向 B：上下分区工作台

**核心理念**：放弃传统 sidebar，采用顶部水平导航 + 上下分区（上方控制面板 + 下方结果画布），类似音频工作站(DAW)的布局逻辑。

**解决的问题**：P1（导航重构）、P2（空间利用）、P4（格式选择器脱节）、P6（情感控制过载）

**布局骨架：**
```
┌──────────────────────────────────────────────────────┐
│ 🎙 TTS MultiMode    [设计声音][克隆][情感][设置]...   │ ← 水平 Tab 导航
├──────────────────────────────────────────────────────┤
│  📐 输出: [wav][mp3]  │  🖥 VoxCPM2 [加载] │ GPU ● │ ← 控制条
├──────────────────────────────────────────────────────┤
│                                                      │
│  ┌─ 控制面板 (上方 40%) ─────────────────────────┐   │
│  │  文本输入  │  声音描述  │  高级参数            │   │
│  │  语言选择  │  标签选择  │                      │   │
│  └────────────────────────────────────────────────┘   │
│                     [ 🎵 生成试听 ]                    │
│  ┌─ 结果画布 (下方 60%) ─────────────────────────┐   │
│  │                                                │   │
│  │  波形可视化 · 播放控制 · 下载 · 保存音色        │   │
│  │                                                │   │
│  └────────────────────────────────────────────────┘   │
│                                                      │
└──────────────────────────────────────────────────────┘
```

**水平 Tab 导航**：所有功能平铺为顶部一行 Tab，按频率分组：
- 常用：声音设计 / 语音克隆 / 极致克隆 / 情感控制
- 工具：剧本 / Prompt / LoRA / 时长控制
- 系统：设置 / 历史 / 音色库 / 帮助

**控制条**：将格式选择、引擎状态、GPU 监视整合为一条窄控制条，位于 Tab 和内容之间。

**5 个页面布局：**

| 页面 | 控制面板 (上方 40%) | 结果画布 (下方 60%) |
|------|-------------------|-------------------|
| 声音设计 | 文本+语言+描述+标签+参数 (两列网格) | 波形+播放+保存 |
| 语音克隆 | 文本+语言+参考音频+参数 (两列网格) | 波形+播放+保存 |
| IndexTTS2 情感 | 模式选择+参考音频+情感预设+滑块+文本 (三列网格) | 情感可视化+结果 |
| 设置 | 全宽参数卡片网格 (scrollable) | **隐藏**，控制面板扩展至 100% |
| 音色库 | 搜索+筛选+卡片网格 (scrollable) | **隐藏**，控制面板扩展至 100% |

**情感控制的特殊处理**：利用控制面板的宽度，情感预设按钮+滑块采用两列网格排列，避免垂直滚动过多（解决 P6）。

### 方向 C：分层卡片流

**核心理念**：将每个功能区块封装为独立卡片，垂直排列，居中对齐（max-width 680px）。卡片可折叠/展开，形成"洋葱式"渐进披露。Sidebar 保留但大幅精简。

**解决的问题**：P1（导航精简）、P2（空间利用—通过卡片聚焦）、P5（设置页割裂—统一卡片范式）、P6（情感控制—可折叠卡片分层）

**布局骨架：**
```
┌──────────┬─────────────────────────────────────────┐
│          │  Top Bar: [折叠][标题]  [引擎][状态]      │
│ Sidebar  ├─────────────────────────────────────────┤
│ (180px)  │         ┌──────────────────────┐         │
│          │         │  📝 合成文本           │ ← 卡片1 │
│ 快速入口  │         │  [textarea]  0/8192   │         │
│ ──────   │         ├──────────────────────┤         │
│ 声音设计  │         │  🎨 声音设计           │ ← 卡片2 │
│ 语音克隆  │         │  描述/标签/语言        │         │
│ 情感控制  │         ├──────────────────────┤         │
│ 极致克隆  │         │  ⚡ 高级参数    [▸]   │ ← 折叠  │
│ ──────   │         ├──────────────────────┤         │
│ 工具      │         │  [🎵 生成试听]        │ ← 操作  │
│ 设置     │         ├──────────────────────┤         │
│ 音色库   │         │  🎵 生成结果           │ ← 结果  │
│ 历史     │         │  波形/播放/下载/保存   │         │
│ 帮助     │         └──────────────────────┘         │
│          │                                         │
│ [☀️][🌐]  │                                         │
└──────────┴─────────────────────────────────────────┘
```

**Sidebar 极简设计**：仅保留 8-9 个最高频入口（去掉 Prompt 续写、LoRA、LoRA 训练、时长控制等低频 Tab，将它们收纳到"更多"菜单或对应页面的子选项中）。

**卡片统一范式**：所有页面都使用相同的卡片结构，只是卡片内容不同——这解决了设置页割裂问题（P5）。

**5 个页面的卡片组成：**

| 页面 | 卡片 1 | 卡片 2 | 卡片 3 | 卡片 4 |
|------|--------|--------|--------|--------|
| 声音设计 | 合成文本 | 声音描述+标签 | 高级参数(折叠) | 生成+结果 |
| 语音克隆 | 合成文本 | 参考音频选择 | 高级参数(折叠) | 生成+结果 |
| IndexTTS2 情感 | 模式选择 | 参考音频+情感控制 | 合成文本 | 生成+结果 |
| 设置 | 引擎信息+GPU(并排) | 高级生成参数 | 默认生成参数 | 通用设置+保存 |
| 音色库 | 搜索+操作 | 音色卡片网格 | — | — |

**卡片折叠交互**：高级参数等非核心卡片默认折叠（仅显示标题行），点击展开。减少初始认知负荷，同时保持信息可达。

### 方向 D：混合自由画布

**核心理念**：采用类 IDE 布局——左侧窄导航栏(icon-only) + 中央主画布 + 可收起的右侧上下文面板 + 底部状态栏。导航分为"生成"和"管理"两大模式，模式切换时整体布局自动调整。

**解决的问题**：P1（导航精简）、P2（空间利用）、P3（Top Bar 精简）、P4（格式选择器归位）、P7（暗色主题一致性）

**布局骨架：**
```
┌────┬─────────────────────────────┬──────────────────┐
│    │  生成模式                    │                  │
│ 图 │  [声音设计][克隆][极致][情感] │  上下文面板       │
│ 标 │─────────────────────────────│  (可收起 280px)   │
│ 导 │                             │                  │
│ 航 │     主画布区                  │  结果/预览/详情    │
│ 栏 │     (flex:1, max-width约束)  │                  │
│    │                             │  波形+播放+下载   │
│ 48 │                             │  +保存+历史      │
│ px │                             │                  │
├────┴─────────────────────────────┴──────────────────┤
│ 🟢 GPU 0% │ VRAM 2.1/8GB │ RAM 12.8GB │ wav │ 🔊  │ ← 底部状态栏
└──────────────────────────────────────────────────────┘
```

**两种布局模式**：
- **生成模式**：icon 导航 + 顶部子 Tab + 中央画布 + 右侧面板。用于声音设计、克隆、情感控制等输入→生成页面。
- **管理模式**：icon 导航 + 中央全宽画布。用于设置、音色库、历史记录。右侧面板自动收起。

**Icon 导航栏 (48px)**：仅显示图标，hover 弹出 tooltip 显示名称。分组用分隔线区分：
- 第一组(生成)：声音设计 / 语音克隆 / 极致克隆 / 情感控制
- 第二组(工具)：剧本 / LoRA / 时长控制
- 第三组(系统)：设置 / 历史 / 音色库

**底部状态栏**：将 GPU/VRAM/RAM 监视 + 输出格式选择 + 音量控制全部整合到 28px 高的底部状态栏中。这彻底解决了 P3（Top Bar 过密）和 P4（格式选择器脱节）。

**Top Bar**：极简化——仅 `[页面标题] ────────── [▶ 引擎状态]`，无其他元素。

**5 个页面布局：**

| 页面 | 模式 | 主画布 | 右侧面板 |
|------|------|--------|---------|
| 声音设计 | 生成 | 文本→描述/标签→参数→生成按钮 | 结果波形+保存 |
| 语音克隆 | 生成 | 文本→参考音频→参数→生成按钮 | 结果波形+保存 |
| IndexTTS2 情感 | 生成 | 模式→参考音频→情感滑块→文本→生成 | 结果+情感可视化 |
| 设置 | 管理 | 引擎信息+GPU+参数卡片 (全宽) | 自动收起 |
| 音色库 | 管理 | 搜索+卡片网格 (全宽) | 选中时展开显示详情 |

## 四、每个原型覆盖的 5 个页面内容清单

### 4.1 声音设计 (Voice Design)
- 合成文本 textarea + 字数统计 (0/8192)
- 语言选择器 (Auto 下拉)
- 子模式切换：描述创建 | 已保存音色
- 声音描述输入 + 推荐格式提示（[年龄][性别][场景][语气]）
- 音色标签网格（甜美萝莉/成熟御姐/磁性男声/低沉男低音/活力少年/日系甜美）
- 高级参数折叠区
- 生成试听按钮 + Ctrl+Enter
- 音色名称输入 + 固化到音色库

### 4.2 语音克隆 (Voice Clone)
- 合成文本 textarea + 字数统计
- 语言选择器
- 子模式切换：已保存音色 | 上传参考
- 已保存 Tab：下拉选择 + 刷新按钮
- 上传 Tab：文件上传区 + 参考文本 + 控制指令
- 高级参数折叠区
- 开始克隆按钮
- 音色名称输入 + 保存按钮

### 4.3 IndexTTS2 情感控制
- 模式选择（3 按钮：同提示词 / 不同提示词 / 文本描述）
- 同提示模式：参考音频上传 + 情感预设 (angry/cry/fear/depressed/happy/surprise/calm) + 滑块
- 文本描述模式：参考音频 + 情感描述输入 + 滑块
- 合成文本输入
- 生成按钮

### 4.4 设置 (Settings)
- 快速导航锚点
- 引擎信息卡片
- GPU VRAM 进度条
- 高级生成参数（自动重试、重试次数、时长比率、目标响度、空闲超时、VAD）
- 默认生成参数（采样率 24000、语速 1、种子 42、段间静音 0.4）
- 通用设置（自动加载、离线模式、API 认证）
- 保存按钮

### 4.5 音色库 (Persona)
- 统计卡片
- 搜索栏 + 视图切换（卡片/列表）
- 操作按钮行（搜索、清除、刷新、创建）
- 卡片网格（gf1/南宫婉/御姐 示例）
- 每卡片：名称 + 描述 + 标签 + 操作

| 问题 | A 任务导向双栏 | B 上下分区工作台 | C 分层卡片流 | D 混合自由画布 |
|------|:---:|:---:|:---:|:---:|
