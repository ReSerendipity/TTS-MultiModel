# TTS MultiModel WebUI 设计风格深度分析计划

## 概述

对 TTS MultiModel 项目的 WebUI 进行全面的设计风格分析，从**代码层面**（CSS 设计令牌、组件系统、布局架构）和**视觉层面**（页面截图、交互快照）两个维度进行深入剖析，最终输出一份综合性的 Markdown 分析建议文件。

## 当前状态分析

### 已完成的研究

1. **代码层面分析** — 已完成，通过 Explore 子代理深入分析了全部 7 个 CSS 文件、21 个 JS 文件、HTML 模板结构
2. **视觉层面分析** — 已完成，通过：
   - 启动服务器（`http://127.0.0.1:7869`）并浏览全部 14 个标签页
   - 获取每个页面的 accessibility snapshot（结构、组件、交互元素）
   - 读取项目中已有的截图文件（`docs/screenshots/` 目录下的暗色主题截图）
   - 阅读浏览器测试报告（`docs/browser_test_report_v2.md`）

### 关键发现摘要

**设计风格定位**：现代专业级音频工作站风格（Audio Workstation），以 Cyan/Teal 为品牌色，暗色主题为默认视觉。

**代码架构亮点**：
- 三层颜色架构（Primitive → Semantic → Component）
- 4px 基准网格间距系统
- CSS `@layer` 级联控制
- 完善的暗色/亮色双主题系统
- Material Design 标准缓动函数
- 毛玻璃效果（backdrop-filter）
- 响应式断点体系（5 级）

**视觉层面发现**：
- 侧边栏 + 主内容区经典 App Shell 布局
- 按引擎分组的导航结构（VoxCPM2 / IndexTTS 2.0 / 工具）
- 卡片式内容组织，统一的表单组件
- 预设音色标签快速选择
- 实时系统监控（GPU/VRAM/内存）
