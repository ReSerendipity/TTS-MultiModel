# 暮山紫（#5D4A7C）品牌色迁移计划

## 一、目标定义

将 TTS_MultiModel 项目的品牌色从 Cyan（青色 #0891B2）迁移到暮山紫（#5D4A7C），覆盖亮/暗双模式，保留三层 CSS 变量架构和所有非品牌色功能色。

### 成功标准
1. 所有品牌色引用从青色调变为紫色调，无遗留 cyan 色值
2. 亮模式下主色在白色背景上达到 WCAG AA（4.5:1 以上）
3. 暗模式下主色在深色背景上达到 WCAG AA（4.5:1 以上）
4. 现有 purple role-tag 色系（#7C3AED 系列）不受影响
5. 所有功能色（green/success, red/error, amber/warning, blue/info）保持不变
6. 所有布局变量（spacing, radius, font, shadow, animation）保持不变
