## 🗑️ 已从规划中移除的任务

以下任务已于 2026-08-13 从项目规划中**正式移除**：

### 1. GPT-SoVITS v3 引擎集成
**移除原因**: 项目已在 `docs/adr/0001-remove-gptsovits.md` 中正式决策删除 GPT-SoVITS 引擎

### 2. CosyVoice v3 实际推理集成
**移除原因**: 需下载 ~5GB+ 模型权重并安装额外依赖

### 3. Flow Matching 技术预研 / 实际训练
**移除原因**: 新型生成模型架构需大量研究工作，需专门 ML 研究环境

### 4. ONNX 部署
**移除原因**: 需将 PyTorch 模型转换为 ONNX，当前环境缺乏 GPU 和完整模型权重

### 5. vLLM/TensorRT 加速
**移除原因**: vLLM Windows 兼容性差，TensorRT 需特定 GPU 工具链

### 6. DPO 训练管线
**移除原因**: DPO 训练需高质量偏好数据集和大量计算资源

### 7. 双向流式推理
**移除原因**: 需 LLM 引擎原生支持双向流，当前引擎仅支持单向流
