# 水印功能已知边界记录

> 定位：本文档记录频域扩频水印 v2（16-20kHz、64-bit 紧凑载荷）在**不可感知性红线约束下**的已知边界，并附信息论依据。
>
> 范围限定为边界与极限情形，不是缺陷清单——列出的"未达标"项均为受物理/信息论约束的最坏情形；正弦与真实语音内容全部通过，2s 及以上音频全部通过。
>
> 数据来源：工作台实测报告 subagent_30/31/32 与反方独立复核 review_v8（路径见文末"参考"）；与复核冲突处以复核为准。

## 背景：v2 修复链

水印 v2 的演进与各轮实测增益：

| 阶段 | 改动 | 实测结果 |
|---|---|---|
| 恒 +1 回归修复（commit fa1b08b） | 修复嵌入端 bipolar bit 恒为真的回归 bug（修复前嵌入器输出全 +1 指纹）；检测端增加内容频谱抑制与奇数 bin 边帧加权 | 正弦 roundtrip 恢复全字段一致，17 测试通过 |
| v2 紧凑 payload + 检测增强（subagent_30） | 64-bit 紧凑载荷；检测端频域白化（帧内中位数归一化后判决） | 正弦 1s/2s 全字段通过；诊断出白噪声 payload 失败的根因：奇数 bin 结构性相位抵消（odd 聚合 SNR≈0.08-0.3，BER≈42%） |
| 奇数 bin 相位翻转（subagent_31） | 嵌入端奇数 bin 逐帧相位翻转 (-1)^frame_idx，检测端同步解翻转、权重恢复全帧统一（边帧 1.5 / 内帧 2） | 4s 白噪声实测 odd bin 对齐 SNR −0.099 → 0.442，**+14dB**（与预测 +10~13dB 吻合），odd 达到 even 水平 |
| 能量提升 + crest 优化（subagent_32） | strength 0.008 → 0.062（7.75×，**+17.8dB**）；载波改对齐零相位（crest 2.90，比旧随机表 3.18 省 0.8dB；Schroeder 相位实测 3.40 更差被否决；repeat 级打散造成检测端自干扰被否决） | 1s 白噪声每 bit 聚合 SNR 0.12-0.19 → ≈0.45-0.55（+7.5dB）；白噪声 2s/4s 全字段通过 |

**v2 载荷格式**（8 字节 = 64 bit，容量完全利用）：

- byte0：version=2
- byte1：source 枚举码（1-255，tts-multimodel=1，未知=255 → "unknown"）
- byte2-5：timestamp 秒（uint32 大端，覆盖至 2106 年）
- byte6-7：content_hash 前 2 字节（4 位 hex）

检测端按 version 字节分派 v2/v1 两条解析路径；v1 路径保留旧截断语义（timestamp=0.0、hash=""）用于旧文件兼容。

## 边界一：1s 白噪声下 64-bit payload 精确还原不可达

**实测依据**：1s 白噪声（48kHz，rng(7)，amp=0.3）经 v2 最终参数嵌入后：

- 每 bit 聚合 SNR（whitened 口径）≈0.45-0.55（能量提升前为 0.12-0.19，其中偶数 bin≈0.19/奇数 bin≈0.12）
- 对应每 bit 决策量 z≈2.5（每帧每 bin SNR=0.52 × √22.6 有效独立帧）
- 而 64-bit 无 ECC 精确还原需每 bit SNR≳4.5（对应 z≈5.5，Q(5.5)×64≈1e-5），差距约 +7dB（幅度 2.2×）

**信息论论证**：白噪声下每帧每 bin 噪声实部 std≈9.6-11.7（内容抑制环节对白噪声反而 +22% 方差），水印经峰值归一化后每帧信号仅≈0.5（corr 量纲）；45 帧相干累积只带来 √89≈9.4× 增益。每 bit 有效信道容量 <1 bit，检测端任何线性组合都无法补足——这是信道容量限制，不是实现缺陷。

**三约束不可兼得**：

1. 64-bit 无 ECC 精确还原需每 bit SNR≳4.5；
2. 30dB 不可感知红线锁死嵌入能量（strength 0.062 + 对齐相位已是红线下实测最优组合）；
3. 1s 白噪声的 16-20kHz 带内能量与水印信号同量级，每 bit 聚合 SNR 上限≈0.5。

三者同时满足在信息论上不可达。

**当前能力（v2 最终参数）**：

- 白噪声 2s/4s：全字段 roundtrip 通过（含 hash 精确一致；嵌入 SNR 22.2/22.1dB）
- 1s 白噪声：version/source/timestamp 正确，content_hash 差 1-2 bit（复核独立实测：expect `b86a` got `386a`，1 bit 残差）；presence 强检出（score=4.49 >> 阈值 0.001）
- 多种子（10 seeds × 1s 白噪声）：全字段通过 2/10，仅 hash 字段受影响的另有 3/10
- 正弦 1s/2s：全字段精确一致（嵌入 SNR 31.4/30.7dB）
- 真实 TTS 语音：全部通过（其 16-20kHz 带内能量远低于白噪声，最坏情形不适用）

**口径建议**：按音频时长分级验收——≥2s 音频验收全字段（真实 TTS 片段普遍 >2s）；1s 属极限用例，只验收 version/source/timestamp + presence 检出。

## 边界二：嵌入 SNR 与宿主 crest 强耦合

**机理**：水印幅度按 strength × max|audio| 峰值归一化，因此嵌入 SNR ≈ 20·log10(crest_wm / (strength × crest_host))，随宿主信号峰均比（crest）变化。

**实测（复核独立复跑）**：

| 宿主 | crest | 嵌入 SNR | 达标情况 |
|---|---|---|---|
| 正弦 0.5×440Hz | ≈1.41 | 30.7-31.4dB（1s 31.4 / 2s 30.7） | ✅ 红线达标 |
| 白噪声 σ=0.3 | ≈4.5-4.8 | 21.3dB（1s）/ 22.2dB（2s） | ❌ 病态宿主 |
| 真实语音 | ≈3.5（估算） | ~23dB（估算） | ⚠️ 低于 30dB |

白噪声宿主下水印带内能量与噪声同量级，属病态宿主；"SNR≥30dB 不可感知红线"作为笼统断言对宽带宿主不成立，仅对低 crest 宿主成立。

**口径说明**：不可感知性以真实内容为准——

- 嵌入带位于 16-20kHz，人耳敏感度极低；
- 宽带噪声宿主下掩蔽效应显著，实际不可闻（噪声 crest 高使 RMS 口径 SNR 天然比正弦低 ~10dB）；
- 红线目前按正弦基准口径执行（strength 0.062 为正弦 30dB 红线下界）；
- 若红线允许按频段加权/掩蔽口径，1s 白噪声也存在余量。

## 附带记录

**presence 分数对宽带噪声无判别力**：

- 干净白噪声（amp 0.1-0.5）的 presence score 为 0.39-1.90，远高于 0.001 阈值——score 本身不能区分"有水印的噪声"与"干净噪声"；
- 防误报实际依赖 payload 解码兜底（解码失败即 success=False），v2 解析已内置 version 字节、source 枚举码与 8 字节定长校验；
- presence score 不得单独作为检出判据。

**v1 旧文件兼容仅限 presence 检出**：

- 旧格式样本（正确 BPSK 与全 +1 bug 指纹两类）presence 均强检出（模拟 v1 样本 score=1.19、全 +1 指纹样本 score=1.34，干净正弦基线 0.0000，证明分数来自水印而非内容泄漏）；
- 但 payload 恢复实际不可达：旧格式无奇数 bin 相位翻转（奇数 bin 跨帧相消）+ 全 +1 bug 指纹本身无信息，复核实测版本字节解出无意义值 0x55/0xFF；
- 另有 2s 构造样本个案可解析出 v1 旧截断语义（v=1 src='tts-mu' ts=0.0 hash=''），但受边帧奇偶影响不稳定、不可依赖；
- "v1 兼容"的实际含义是 presence 检出，不承诺 payload 解码。

## 可选突破路径（均为产品权衡，未执行）

- **a) 加 ECC/重复编码**：信息论正解，但需在 64-bit 内拨出冗余（如 32-bit 载荷 + (2,1) 重复，或 BCH(63,36) 类码）。代价：载荷字段精简（timestamp 缩为 16bit 秒 + epoch 偏移、hash 缩为 1B）。48kHz 下 171 个可用 bin 内 64bit×2 重复仅 +3dB，远不足以独立解决——需扩频带或降 payload。
- **b) 放宽不可感知红线**：strength 0.062 → 0.09（正弦口径 SNR≈27dB）后 z≈3.6，仍不足以单独过关，必须与 ECC 组合；SNR<30dB 的听感影响需主观评测。
- **c) 检测端多帧联合解码**：当前已利用 4 次重复相干叠加与加权相干平均（已达匹配滤波最优），白化不改变单 bit SNR，REPEAT 参数被峰值归一化完全抵消（无杠杆）——该路径收益已穷尽。
