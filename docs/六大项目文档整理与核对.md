**正确启动姿势（4 个 Python 项目）**：

```bat
cd <项目根>
.venv\Scripts\activate        :: 激活虚拟环境（或直接 .venv\Scripts\python -m ...）
python -m uvicorn <入口模块>:app --port <端口>
```

四个 `.venv` 均由 `C:\Python312\python.exe -m venv` 创建，`include-system-site-packages = false`，依赖全在项目内。
