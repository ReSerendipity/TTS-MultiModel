## 🗑️ 任务移除说明

以下任务已于 2026-08-13 从项目规划中**正式移除**：

### 1. GPT-SoVITS v3 引擎集成
**移除原因**: 项目已在 ADR-0001 中正式决策删除 GPT-SoVITS 引擎

### 2. CosyVoice v3 实际推理集成
**移除原因**: 
- 需下载 ~5GB+ 模型权重
- 当前环境无法完成模型下载和真实推理测试

### 3. Flow Matching 技术预研 / 实际训练
**移除原因**: 
- 新型生成模型架构需大量研究工作和模型架构改造
- 需要专门的 ML 研究和实验环境
- 已完成的仅为理论设计文档

### 4. ONNX 部署
**移除原因**: 
- 需将 PyTorch 模型转换为 ONNX 格式
- 当前环境缺乏 GPU 和完整的模型权重
- 无法验证转换后的 ONNX 模型推理正确性

### 5. vLLM/TensorRT 加速
**移除原因**: 
- vLLM 主要面向 Linux 部署，Windows 兼容性差
- TensorRT 需要 NVIDIA 特定 GPU 和完整 CUDA 工具链
- 当前在 Windows 平台部署这些加速库成本高

### 6. DPO 训练管线
**移除原因**: 
- DPO 训练需要高质量偏好数据集和大量计算资源
- 与删除 GPT-SoVITS 的架构决策相关联

### 7. 双向流式推理
**移除原因**:
- 需要 LLM 引擎原生支持双向流
- 当前引擎仅支持单向流，重构成本高
