# Personas（音色库）说明

本目录存放 TTS_MultiModel 的音色（persona）模型与演示文本。

## 音色来源与许可

- 所有音色均为 **AI 合成原创音色**（通过文本描述/合成方式生成），**不包含任何第三方配音演员或真人声音的克隆**；
- 训练基座：**VoxCPM2（Apache-2.0）**，本目录中的 `.pt` 为基于该基座的 LoRA/微调产物——衍生品可自由使用与再分发（遵守 Apache-2.0 署名要求）；
- `.wav` 为本地演示音频，已被 `.gitignore` 排除，不随仓库分发。

## 命名说明

- 角色名（如"韩立""南宫婉"等）仅为**演示标签**，音色与任何作品、角色、演员无关；
- 测试文本（`.txt`）均为原创内容。
