        TTSMultiModel 桌面版 —— 安装须知与用户条款（请仔细阅读）
==========================================================================

安装前请阅读并充分理解以下内容。点击「我同意」继续安装，即视为您接受
全部条款；不同意请点击「取消」退出安装。

一、安装与环境告知
  1. 系统要求：Windows 10 / 11（64 位）；需系统 WebView2 运行时
     （Win10 21H2+/Win11 已内置，精简系统需自行安装）。
  2. 磁盘空间：完全安装约需 31GB（应用 + 随包便携 Python 运行时 +
     PyTorch + 5 个语音模型），安装耗时约 5~15 分钟，请勿中途关闭。
  3. 本地运行：本软件完全在本机运行，无需联网即可使用全部合成功能；
     按当前用户安装，无需管理员权限。
  4. 自动更新：仅访问 GitHub 公开发布接口检查新版本，不传输任何
     个人数据；可在应用内关闭自动检查。

二、合法使用承诺（重要）
  1. 语音克隆/声音设计功能，仅可对【您拥有合法权利或已获得明确授权】
     的音频使用。
  2. 严禁将本软件用于：冒充他人身份实施诈骗或损害他人名誉、伪造或
     传播虚假信息、赌博、色情以及其他任何违反法律法规与公序良俗的活动。
  3. 本软件生成的音频默认嵌入【不可感知的内容来源标识（水印）】，用于
     AI 生成内容识别与来源追溯。请勿移除或篡改该标识，并在对外发布
     AI 生成合成内容时，遵守所在司法辖区的标识义务
     （如中国《人工智能生成合成内容标识办法》）。
  4. 您使用本软件生成、传播的内容由您自行负责其合法合规。

三、隐私声明
  1. 您的文本、上传音频、历史记录与生成的全部数据均保存在本机
     （安装目录与 %APPDATA%\TTSMultiModel），软件不会上传任何用户数据。
  2. 删除数据或卸载时，历史记录与音频将一并清除。

四、第三方模型与许可（本包含随分发模型，权重版权属各权利人）

    License ——【商用需取得 bilibili 书面授权】，请以官方条款为准。
  - 完整第三方组件清单见安装目录 THIRD_PARTY_NOTICES 与 NOTICE 文件。
